# flutter-ar-scene-viewer

ARCore and ARKit 3D GLTF model viewer widget with gesture scaling and surface placement.

`#flutter` `#augmented-reality` `#arcore` `#arkit` `#3d-models`

## Highlights
- Modular, clean architecture
- Documented API and straightforward integration
- Tested for performance and stability

## Quick Overview
```
// AR Scene configuration options
class ArSceneConfig {
  final bool planeDetection;
  final bool lightEstimation;
  ArSceneConfig({this.planeDetection = true, this.lightEstimation = true});
}

```
